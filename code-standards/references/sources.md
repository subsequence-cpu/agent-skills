## 更新策略

1. 查阅外部指南前先检查仓库工具。
2. 规范可能变化或任务要求精确合规时，使用最新官方来源。
3. 将上游示例视为语言指导，不视为全仓库重新格式化的授权。
4. 保持 Java 冲突处理原则：仓库工具优先；否则采用 Google 格式和黄山版衍生工程约束。
5. 上游规则发生实质变化时更新摘要，并在本文件记录来源链接。
